📖 Como restaurar o .bak do PHC
1. Instalar SQL Server Express 2022
Descarregar grátis em aka.ms/sqlserver2022express
Escolher instalação Basic — corre em background no Windows.

2. Instalar SQL Server Management Studio (SSMS)
Descarregar em aka.ms/ssmsfullsetup
Ferramenta gráfica para gerir a base de dados.

3. Restaurar o ficheiro .bak
Abrir SSMS → ligar a localhost\SQLEXPRESS
Clicar direito em Databases → Restore Database…
Escolher Device → selecionar o ficheiro .bak
Definir nome da BD (ex: PHC) → OK.

4. Criar utilizador SQL só-leitura (recomendado)
No SSMS → Security → Logins → New Login…
Nome: comprasnet_ro | Password à escolha
Em User Mapping: selecionar BD PHC → role db_datareader

5. Instalar driver ODBC
Descarregar ODBC Driver 18 for SQL Server da Microsoft.
Executar o instalador e reiniciar o ComprasNet.

6. Configurar acima e clicar "Testar Ligação"
