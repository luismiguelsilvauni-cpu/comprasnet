2. Cálculo da média de consumo
Média mensal = Total vendido ÷ Período total
{{ '%.3f'|format(periodo.media_mensal) }} {{ result.unidade }}/mês = {{ '%.1f'|format(periodo.total_vendido) }} ÷ {{ periodo.meses_periodo }} meses
Média anual = Média mensal × 12
{{ '%.2f'|format(periodo.media_anual) }} {{ result.unidade }}/ano = {{ '%.3f'|format(periodo.media_mensal) }} × 12
💡 A média usa o período total desde a 1ª venda (não apenas os meses com vendas), para reflectir a procura real incluindo meses sem venda. Um artigo vendido 10 unidades há 5 anos tem média de 2/ano, não 10/ano.
3. Stock de segurança
Consumo diário = Média mensal ÷ 30
= {{ '%.3f'|format(result.consumo_medio_diario) }} {{ result.unidade }}/dia
Stock segurança = Factor segurança × Consumo diário × Lead time
{{ '%.2f'|format(result.stock_seguranca) }} {{ result.unidade }} = {{ config.fator_seguranca }} × {{ '%.4f'|format(result.consumo_medio_diario) }} × {{ config.lead_time_dias }} dias
4. Ponto de Reorder (ROP)
ROP = (Consumo diário × Lead time) + Stock segurança
{{ '%.2f'|format(result.ponto_reorder) }} {{ result.unidade }} = ({{ '%.4f'|format(result.consumo_medio_diario) }} × {{ config.lead_time_dias }}) + {{ '%.2f'|format(result.stock_seguranca) }}
⚠️ Quando o stock desce abaixo de {{ '%.2f'|format(result.ponto_reorder) }} {{ result.unidade }}, deve ser feita uma encomenda. Stock actual: {{ '%.1f'|format(result.stock_atual) }} → {% if result.precisa_encomendar %}Abaixo do ROP — encomendar!{% else %}Acima do ROP — OK{% endif %}
5. Quantidade Económica de Encomenda (EOQ)
D = Consumo anual = {{ '%.2f'|format(result.consumo_medio_mensal * 12) }} {{ result.unidade }}/ano
S = Custo por encomenda = {{ config.custo_encomenda }}€
H = Custo posse unitário = P. Custo × Taxa posse = {{ '%.2f'|format(result.preco_custo) }}€ × {{ (config.taxa_posse_anual * 100)|round(1) }}% = {{ '%.2f'|format(result.preco_custo * config.taxa_posse_anual) }}€/ano
EOQ = √(2 × D × S ÷ H)
{{ '%.1f'|format(result.eoq) }} {{ result.unidade }} = √(2 × {{ '%.1f'|format(result.consumo_medio_mensal * 12) }} × {{ config.custo_encomenda }} ÷ {{ '%.4f'|format(result.preco_custo * config.taxa_posse_anual) }})
💡 O EOQ é a quantidade que minimiza o custo total (encomenda + armazenamento). Encomendar menos vezes com mais quantidade, ou mais vezes com menos? O EOQ dá o equilíbrio óptimo.
