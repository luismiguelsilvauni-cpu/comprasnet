📖 Como instalar e configurar o LM Studio
1. Instalar LM Studio
Descarregar em lmstudio.ai → botão "Download for Windows" → instalar normalmente.

2. Descarregar um modelo
Abrir LM Studio → separador "Discover" (ícone 🔍)
Pesquisar: qwen2.5-7b-instruct
Clicar no resultado → botão Download (≈4.5 GB, demora consoante a ligação)

3. Carregar o modelo
Separador "Chat" → no topo, clicar em "Select a model" → escolher o modelo descarregado.
Aguardar carregar (barra de progresso no fundo).

4. Ativar o servidor local
Separador "Local Server" (ícone ↔️ ou <->)
Clicar "Start Server" → deve aparecer "Running on port 1234"
⚠️ Este passo é obrigatório — sem o servidor ativo, o ComprasNet não consegue comunicar.

5. Copiar o nome do modelo
No separador Local Server, o nome do modelo aparece no topo (ex: qwen2.5-7b-instruct)
Copiar esse nome exato para o campo "Nome do modelo" acima.

6. Testar
Clicar "Testar Ligação" e depois "Testar Extração PDF" aqui em cima.
💡 Dica para PC partilhado: O LM Studio pode ser configurado para iniciar automaticamente com o Windows. Vá a Settings → General → Launch at startup. O servidor só precisa de estar ativo quando alguém vai usar o ComprasNet para analisar PDFs.
