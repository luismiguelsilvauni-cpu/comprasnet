ℹ️ Como funciona
1. Verificar — compara a versão instalada com a versão mais recente no GitHub.
2. Backup automático — guarda uma cópia da base de dados antes de qualquer alteração.
3. Download — descarrega só os ficheiros que mudaram (git pull).
4. Migração — actualiza a base de dados se necessário (preserva todos os dados).
5. Reinício — o servidor reinicia automaticamente com a nova versão.

💡 Para que as actualizações automáticas funcionem, o repositório GitHub tem de estar sincronizado com as alterações mais recentes. Se não houver actualizações disponíveis significa que está na versão mais recente.
