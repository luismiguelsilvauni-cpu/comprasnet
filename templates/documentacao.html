📖 Documentação NavTech

Guia completo de todas as funcionalidades do sistema de gestão integrada. Cada secção descreve o propósito do módulo, as suas funcionalidades principais e como utilizá-lo. Esta documentação actualiza-se automaticamente com cada nova versão do software.

⊞ Visão Geral
⊞
Dashboard
Página inicial — visão geral do estado da empresa
▾

O Dashboard é a página inicial do sistema e apresenta os indicadores mais relevantes da actividade da empresa numa única vista: pedidos pendentes, stock crítico, assistências abertas, próximos serviços agendados e alertas de documentos a expirar.

Funcionalidades
  • KPIs em tempo real — pedidos, orçamentos, entradas, assistências
  • Alertas de stock mínimo — artigos abaixo do ponto de encomenda
  • Próximos serviços — agenda dos próximos dias
  • Documentos a expirar — certidões e seguros com prazo próximo
  • Actividade recente — últimas acções no sistema
Como utilizar
  1. Aceder após login — é a página de entrada
  2. Verificar alertas de stock e documentos no topo
  3. Clicar nos tiles para navegar directamente para cada módulo
  4. Usar os atalhos rápidos para criar pedidos ou assistências
O Dashboard actualiza-se automaticamente. Os badges nos menus da sidebar também mostram contagens em tempo real (ex: pendentes, backlog).

Agenda Digital
Gestão de serviços, técnicos e registos diários de trabalho
▾

A Agenda Digital substitui folhas de horas e tabelas de serviços em papel. Permite criar serviços, atribuir técnicos por dia, registar horas, materiais aplicados e deslocações, e gerar automaticamente mapas de trabalho em PDF.

Funcionalidades
  • Criação de serviços — associar a cliente, embarcação ou equipamento
  • Registos diários — horas normais, horas extra, deslocação, refeições
  • Materiais aplicados — integração com PHC ou registo manual
  • Vista mensal/semanal — calendário visual por técnico
  • Export PDF — relatório de serviço assinável pelo cliente
  • Estatísticas — horas por técnico, custo por serviço
  • Integração com Salários — horas extra exportadas automaticamente
Como utilizar
  1. Criar um novo serviço com cliente e descrição
  2. Definir datas de início e fim previstas
  3. Atribuir técnicos ao serviço
  4. Cada técnico regista o seu dia: horas, materiais, km
  5. Fechar o serviço quando concluído
  6. Gerar PDF do relatório de serviço
Os registos diários alimentam automaticamente os mapas de horas dos funcionários e podem ser exportados para o módulo de Salários.

Clientes
Registo completo de clientes e embarcações/equipamentos
▾

O módulo de Clientes centraliza toda a informação sobre os clientes da empresa: dados de contacto, embarcações associadas, histórico de serviços e assistências, e documentação relevante.

Funcionalidades
  • Ficha de cliente — NIF, morada, contactos, notas
  • Embarcações — nome, matrícula, tipo, especificações técnicas
  • Histórico — serviços, assistências e pedidos do cliente
  • Sincronização PHC — importar clientes do software de gestão
  • Pesquisa rápida — por nome, NIF, matrícula de embarcação
Como utilizar
  1. Pesquisar cliente existente ou criar novo
  2. Preencher dados da empresa e contacto principal
  3. Adicionar embarcações ou equipamentos do cliente
  4. Consultar histórico na ficha do cliente
  5. Usar "Sincronizar PHC" para importar clientes em massa
Ao criar um serviço ou assistência, o sistema sugere automaticamente as embarcações do cliente seleccionado.

Empresa
Dados institucionais e gestão de documentos da empresa
▾

Centraliza toda a informação da empresa — dados fiscais, bancários, seguros — e permite fazer upload e controlar a validade de documentos oficiais como certidões permanentes, não-dívidas, apólices de seguro e outros documentos com prazo.

Funcionalidades
  • Dados institucionais — NIF, NIPC, CAE, conservatória, capital social
  • Dados bancários — banco, IBAN, SWIFT
  • Documentos com validade — upload PDF, alertas de expiração
  • Tipos suportados — certidão permanente, não-dívidas, IBAN, seguros
  • Alertas automáticos — Dashboard avisa documentos a expirar em 60 dias
Como utilizar
  1. Aceder a Gestão → Empresa
  2. Preencher dados da empresa uma única vez
  3. Fazer upload de cada documento com data de validade
  4. O Dashboard alerta automaticamente quando um prazo se aproxima
Os dados da empresa (nome, NIF, IBAN) são usados automaticamente na geração de recibos de vencimento no módulo de Salários.

Fornecedores
Diretório de fornecedores sincronizado com PHC
▾

O módulo de Fornecedores mantém o diretório atualizado com os fornecedores do PHC, complementado com informações de contacto adicionais (NAV fields) que não existem no PHC, como telemóvel, email directo e notas internas.

Funcionalidades
  • Sincronização PHC — dados base sempre actualizados
  • Campos NAV — campos adicionais que não sobrescrevem o PHC
  • Marcas associadas — que marcas/produtos cada fornecedor representa
  • Pesquisa — por nome, NIF, localidade, marcas
Como utilizar
  1. Executar sincronização PHC para importar todos os fornecedores
  2. Completar campos NAV (contacto directo, notas)
  3. Associar marcas representadas a cada fornecedor
  4. Usar pesquisa para encontrar fornecedores por marca ou produto
Para gerir fornecedores de consulta (com avaliações e geração de emails IA), use o módulo Logística → Consultas.

Funcionários
Registo e gestão de recursos humanos
▾

Gestão completa do quadro de pessoal: dados pessoais e contratuais, documentação, ficha de aptidão médica, dados para processamento salarial e atribuição a serviços na Agenda Digital.

Funcionalidades
  • Ficha do funcionário — dados pessoais, NIF, NISS, contrato
  • Documentos — BI, carta de condução, certificados
  • Ficha de aptidão — registo de exames médicos e validade
  • Dados salariais — vencimento base, subsídios, IRS
  • Integração — aparece na Agenda e no módulo de Salários
Como utilizar
  1. Criar ficha do funcionário com dados pessoais
  2. Definir vencimento e dados contratuais
  3. Configurar IRS (escalão, dependentes)
  4. Fazer upload de documentos pessoais
  5. Gerir aptidão médica com data de validade do exame
Os dados configurados aqui são usados automaticamente na geração de recibos de vencimento. Manter sempre o escalão de IRS actualizado.

Mapa Férias / Faltas
Controlo de ausências com saldos automáticos
▾

Sistema completo de gestão de ausências com fluxo de aprovação, cálculo automático de saldos de férias e integração com o calendário da empresa. Suporta 12 tipos de ausência: férias, pontes, baixas médicas, consultas, formação, teletrabalho, entre outros.

Funcionalidades
  • 12 tipos de ausência com impacto diferente nos saldos
  • Vista mensal — mapa visual com cores por tipo
  • Saldos automáticos — dias de férias disponíveis em tempo real
  • Fluxo de aprovação — pendente → aprovado/rejeitado
  • Feriados e fechos — configuráveis por ano
  • Export CSV — para entidades externas
  • Ajustes manuais — transitar dias do ano anterior
Como utilizar
  1. Configurar feriados e fechos da empresa no início do ano
  2. Definir dias de direito a férias por funcionário
  3. Registar ausências com tipo, período e formato (dia/manhã/tarde)
  4. Aprovar ou rejeitar pedidos pendentes (admin)
  5. Consultar saldos actualizados por funcionário
Ausências do tipo "Fériasˮ, "Ponteˮ e "Fecho Empresaˮ descontam automaticamente dos dias de férias disponíveis. Faltas injustificadas e licenças sem vencimento descontam no salário.

Partilha
Partilha de ficheiros entre membros da equipa
▾

Área de partilha interna de documentos e ficheiros entre todos os utilizadores do sistema. Funciona como um repositório acessível a toda a equipa para documentos de uso comum.

Funcionalidades
  • Upload de ficheiros — qualquer formato
  • Organização por categorias — pastas lógicas
  • Acesso partilhado — visível a todos os utilizadores
  • Download directo — aceder sem sair do sistema
Como utilizar
  1. Aceder a Gestão → Partilha
  2. Fazer upload do ficheiro com um título descritivo
  3. Escolher categoria adequada
  4. Qualquer utilizador pode descarregar ou pré-visualizar
Use a Partilha para documentos de uso geral como procedimentos internos, listas de preços, formulários. Para documentos de clientes ou equipamentos específicos, use as fichas respectivas.

Salários
Processamento salarial com cálculo automático de IRS
▾

Módulo de processamento salarial com cálculo automático de IRS, SS, subsídios e horas extra. Gera recibos de vencimento em PDF, envia por email e mantém histórico completo de processamentos.

Funcionalidades
  • Cálculo automático de IRS — tabelas AT actualizadas por escalão
  • Segurança Social — 11% trabalhador + 23.75% empresa
  • Subsídios — alimentação, férias, Natal
  • Horas extra — 25%/37.5%/50% conforme legislação
  • Recibos PDF — geração automática com dados da empresa
  • Envio email — recibo enviado directamente ao funcionário
  • Histórico — todos os processamentos arquivados
  • PIN de acesso — protecção extra para dados salariais
Como utilizar
  1. Configurar dados salariais na ficha de cada funcionário
  2. No início do mês, abrir novo período de processamento
  3. Verificar horas extra (integradas da Agenda)
  4. Confirmar subsídios aplicáveis ao período
  5. Gerar recibos e rever antes de enviar
  6. Enviar recibos por email com um clique
O módulo de Salários está protegido por PIN separado. As horas extra registadas na Agenda Digital são importadas automaticamente para o processamento do mês.

Análise de Inventário
Análise avançada de stock com histórico de preços e fornecedores
▾

Ferramenta de análise profunda do inventário: evolução de preços de compra, comparação entre fornecedores, análise ABC (artigos por valor de consumo), histórico de compras e cálculo de necessidades.

Funcionalidades
  • Histórico de preços — evolução do custo de compra ao longo do tempo
  • Comparação fornecedores — melhor preço por artigo
  • Análise ABC — classificação por valor de consumo
  • Rotatividade — artigos com maior/menor movimento
  • Tendências — crescimento ou redução de consumo
Como utilizar
  1. Seleccionar período de análise
  2. Filtrar por família, fornecedor ou artigo específico
  3. Analisar gráfico de evolução de preços
  4. Identificar artigos de classe A (alto valor) para negociação prioritária
Use a análise ABC para identificar os 20% de artigos que representam 80% do custo de inventário. Estes devem ter stock mínimo definido no módulo de Reposição.

Associações Pendentes
Confirmar correspondências IA entre descrições de fornecedores e artigos PHC
▾

Quando um PDF de orçamento é importado, a IA tenta associar cada linha do orçamento ao artigo correspondente no PHC. As sugestões com menor confiança ficam pendentes para confirmação manual. Ao confirmar, o sistema aprende para o futuro.

Funcionalidades
  • Lista de sugestões IA — descrição do fornecedor vs artigo sugerido
  • Score de confiança — percentagem de certeza da sugestão
  • Confirmar / Rejeitar — treina o modelo de aprendizagem
  • Pesquisa manual — buscar o artigo correcto se a sugestão estiver errada
  • Histórico de aliases — correspondências aprendidas
Como utilizar
  1. O badge na sidebar mostra o número de pendentes
  2. Para cada sugestão, verificar se o artigo sugerido está correcto
  3. Confirmar se correcto — o sistema aprende
  4. Se errado: pesquisar o artigo correcto e associar
  5. Rejeitar se não for possível associar (artigo não existe)
Quanto mais confirmações forem feitas, mais precisa fica a IA na análise automática de PDFs. Idealmente manter as pendentes a zero no final de cada semana.

Consultas a Fornecedores
Base de dados de fornecedores com geração de emails de consulta por IA
▾

Módulo para organizar fornecedores por marca com múltiplos contactos por idioma, avaliações por critério e geração automática de emails de consulta profissionais em português, inglês, francês ou espanhol — usando IA. O utilizador copia o email gerado e envia manualmente.

Funcionalidades
  • Marcas com logotipo — organização visual por fabricante
  • Sub-marcas / referências — gamas de produto indexadas na pesquisa
  • Múltiplos contactos — cada um com nome, email, cargo e idioma
  • Avaliação por estrelas — velocidade, preço, qualidade, fiabilidade
  • Email IA — gera email directo e profissional no idioma do contacto
  • Pesquisa global — por fornecedor, marca, sub-marca, país, contacto
  • Cópia de email — botão para copiar para clipboard
Como utilizar
  1. Criar uma Marca (ex: Volvo Penta) com logotipo
  2. Adicionar fornecedor com país e sub-marcas (ex: "Volvo D6, Volvo IPS")
  3. Adicionar contactos com nome, email e idioma de comunicação
  4. Na página da marca, seleccionar o contacto destinatário
  5. Escrever em português o que pretende consultar
  6. Clicar "✨ Gerar" — o email é gerado no idioma do contacto
  7. Copiar e enviar manualmente por email
O email gerado começa sempre com o primeiro nome do contacto ("Bom dia Jessica,") e vai directo ao assunto, sem introduzir a empresa — curto e profissional. A assinatura deve ser adicionada manualmente.

Entradas de Stock
Registo de recepção de mercadorias com matching de pedidos
▾

Regista a entrada física de mercadorias no armazém. Cada entrada pode ser associada ao pedido de compra correspondente, garantindo rastreabilidade completa desde a encomenda até à recepção em stock.

Funcionalidades
  • Criação de entradas — fornecedor, data, nº guia/factura
  • Linhas de artigo — referência, quantidade, preço unitário
  • Associação a pedido — fechar linhas de pedidos de compra
  • Histórico — todas as entradas arquivadas com PDF
  • Upload de documentos — guias de remessa, facturas
Como utilizar
  1. Ao receber mercadoria, criar nova entrada
  2. Seleccionar fornecedor e introduzir nº de documento
  3. Adicionar linhas com artigos recebidos e quantidades
  4. Associar cada linha ao pedido de compra pendente
  5. Confirmar entrada — stock é actualizado no PHC
Ao associar uma entrada a um pedido, o estado das linhas do pedido passa automaticamente para "Recebido", encerrando o ciclo de compra.

Pedidos de Compra
Criação, aprovação e seguimento de encomendas a fornecedores
▾

Gestão completa do ciclo de compra: criação de pedidos por qualquer utilizador, aprovação pelo responsável, importação de orçamentos PDF por IA, comparação de preços e follow-up até à recepção em armazém.

Funcionalidades
  • Criação de pedidos — artigos PHC ou descrição livre
  • Fluxo de aprovação — aberto → aprovado → em curso → concluído
  • Import PDF IA — orçamentos analisados automaticamente
  • Comparação de propostas — melhor preço destacado
  • Follow-up por linha — estado individual de cada artigo
  • Associação a cliente — pedidos para projectos específicos
  • Estatísticas — valores por período, departamento, fornecedor
Como utilizar
  1. Criar pedido com título e artigos necessários
  2. Submeter para aprovação do responsável
  3. Após aprovação, solicitar orçamentos aos fornecedores
  4. Fazer upload dos PDFs de orçamento — IA extrai os dados
  5. Comparar propostas e escolher a melhor
  6. Encomenda efectuada → registar entrada quando chegar
O sistema aprende com cada PDF importado. Quanto mais PDFs do mesmo fornecedor forem processados, mais precisa fica a extracção automática de artigos e preços.

Reposição de Stock
Alertas automáticos de stock mínimo e geração de pedidos de compra
▾

Analisa automaticamente o stock actual versus os mínimos definidos e apresenta uma lista de artigos a repor. Permite gerar pedidos de compra directamente a partir da lista de reposição, agilizando o processo de encomenda de consumíveis críticos.

Funcionalidades
  • Alertas de stock mínimo — artigos abaixo do ponto de encomenda
  • Quantidade sugerida — baseada no stock mínimo configurado
  • Análise de artigo — histórico de consumo e tendência
  • Criar pedido directo — gera PO a partir da lista de reposição
  • Configuração por artigo — definir stock mínimo e fornecedor preferencial
Como utilizar
  1. Configurar stock mínimo por artigo (página de análise de artigo)
  2. Aceder regularmente à lista de reposição
  3. Verificar artigos abaixo do mínimo
  4. Seleccionar artigos a repor e gerar pedido de compra
  5. O pedido é criado automaticamente com as quantidades sugeridas
Configure stock mínimo nos artigos de maior rotatividade (materiais de consumo frequente, produtos críticos). O Dashboard mostra os alertas de reposição em destaque.

Stock
Consulta em tempo real do inventário sincronizado com PHC
▾

Vista directa sobre o stock actual sincronizado com o PHC CS. Permite consultar quantidades, preços de custo, PVP e histórico de movimentos por artigo. Os dados reflectem sempre o estado actual do PHC após cada sincronização.

Funcionalidades
  • Stock em tempo real — quantidades, preço custo, PVP
  • Pesquisa rápida — por referência ou descrição
  • Ficha de artigo — histórico de preços, fornecedores habituais
  • Notas internas — anotações por artigo (não sobrescrevem PHC)
  • Alertas — stock negativo, abaixo do mínimo
Como utilizar
  1. Pesquisar artigo por referência PHC ou descrição
  2. Ver stock actual e preços actualizados
  3. Clicar na referência para ver detalhe e histórico
  4. Adicionar notas internas se necessário
  5. Executar sincronização PHC para actualizar dados
A sincronização com PHC pode ser configurada para correr automaticamente num horário definido (ex: todos os dias às 06:00). Configurar em Admin → Integração PHC.

Assistências
Ordens de serviço técnico — criação, seguimento e fecho
▾

Gestão completa das ordens de assistência técnica: abertura, atribuição de técnico, registo de intervenção, peças utilizadas, estado e fecho com relatório PDF para assinatura do cliente.

Funcionalidades
  • Criação de OS — cliente, equipamento, descrição do problema
  • Atribuição de técnico — responsável pela intervenção
  • Estados — aberta, em curso, aguarda peças, concluída
  • Histórico de intervenções — log detalhado de acções
  • Peças e materiais — artigos consumidos na assistência
  • Relatório PDF — documento profissional para assinatura
  • Estatísticas — tempo médio resolução, tipos de avaria
Como utilizar
  1. Criar OS com cliente, equipamento e descrição da avaria
  2. Atribuir técnico responsável
  3. Técnico actualiza estado e regista intervenções
  4. Registar peças e materiais utilizados
  5. Ao concluir, fechar OS e gerar relatório PDF
  6. Cliente assina o relatório (digital ou em papel)
O histórico de intervenções por equipamento permite analisar avarias recorrentes e planear manutenção preventiva.

Base de Dados de Embarcações
Ficha técnica completa de embarcações com motores e componentes
▾

Base de dados técnica detalhada de embarcações: casco, motores, sistemas electrónicos, propulsão. Cada embarcação tem ficha própria com especificações técnicas, componentes, documentação e histórico de assistências. Associada a um cliente.

Funcionalidades
  • Ficha técnica — eslora, boca, calado, material, ano
  • Motores — marca, modelo, série, potência, horas
  • Componentes — IPS, jackshaft, eixos, hélices
  • Documentação — certificados, seguros, registo
  • Histórico — todas as assistências da embarcação
  • Pesquisa — por matrícula, modelo de motor, cliente
Como utilizar
  1. Criar ficha da embarcação associada ao cliente
  2. Preencher dados de casco e identificação
  3. Adicionar motores com todos os dados técnicos
  4. Registar outros componentes relevantes
  5. Fazer upload de documentação da embarcação
  6. Consultar histórico de assistências na ficha
A ficha técnica da embarcação é consultada automaticamente quando se cria uma assistência, evitando re-introdução de dados.

Base de Dados Industriais
Gestão técnica de equipamentos industriais (geradores, grupos hidráulicos, etc.)
▾

Similar à base de dados de embarcações, mas orientada a equipamentos industriais: geradores, grupos hidráulicos, motores industriais, quadros eléctricos. Mantém a ficha técnica completa de cada equipamento com componentes, fotos, documentação e histórico.

Funcionalidades
  • Tipos suportados — gerador, grupo hidráulico, motor, outro
  • Componentes detalhados — motor, alternador, quadro
  • Especificações — potência kW/kVA, tensão, frequência
  • Fotos e documentação — upload por componente
  • Localização — onde está instalado
  • Histórico de assistências — ligado ao módulo de Assistências
Como utilizar
  1. Criar equipamento associado ao cliente
  2. Definir tipo (gerador, grupo, motor…)
  3. Adicionar componentes com especificações técnicas
  4. Fazer upload de fotos e documentação técnica
  5. Registar local de instalação
Para geradores, preencha o motor E o alternador como dois componentes separados — cada um com a sua marca, modelo e número de série.

Biblioteca PDF
Repositório de manuais técnicos e documentação organizada por modelo
▾

Biblioteca digital de documentação técnica: manuais de serviço, catálogos de peças, boletins técnicos, diagramas eléctricos. Organizada por marca e modelo, acessível a todos os técnicos em qualquer dispositivo.

Funcionalidades
  • Upload de PDFs — manuais, catálogos, boletins
  • Organização por modelo — marca / linha / modelo
  • Pesquisa — por marca, modelo, palavras-chave
  • Pré-visualização — ver PDF no browser sem descarregar
  • Versões — múltiplos documentos por modelo
Como utilizar
  1. Criar modelo (marca + nome do modelo)
  2. Fazer upload dos PDFs do modelo
  3. Atribuir tipo de documento (manual, catálogo, etc.)
  4. Pesquisar por marca/modelo quando necessário em campo
Aceder à Biblioteca num tablet ou telemóvel durante uma assistência é a forma mais rápida de consultar o manual de serviço sem sair do local de trabalho.

Fichas de Equipamentos
Histórico de manutenção e intervenções por equipamento
▾

Fichas de manutenção preventiva e correctiva de equipamentos. Cada ficha regista o ciclo de vida de um equipamento: componentes, intervalos de manutenção, intervenções realizadas e próximas acções previstas.

Funcionalidades
  • Ficha por equipamento — associada a cliente e embarcação
  • Componentes — lista de peças relevantes com estado
  • Histórico de intervenções — data, técnico, trabalho realizado
  • Próxima manutenção — alerta por data ou horas de funcionamento
  • Documentos — fotos, relatórios, certificados
Como utilizar
  1. Criar ficha para cada equipamento a monitorizar
  2. Definir componentes e intervalos de manutenção
  3. Após cada manutenção, registar a intervenção
  4. Definir data da próxima intervenção prevista
  5. Consultar alertas de manutenção no Dashboard

▾

Plataforma colaborativa para submeter ideias de melhoria, votar em funcionalidades existentes e acompanhar o estado das melhorias planeadas. Qualquer utilizador pode propor. A gestão responde e actualiza o estado.

Funcionalidades
  • Submeter proposta — qualquer utilizador
  • Estados — aberta, em análise, planeada, em curso, concluída, rejeitada

  • Prioridade — normal, alta, crítica

  2. Seleccionar o módulo e prioridade
  3. Acompanhar o estado na lista de propostas
  4. Admin: avaliar e dar resposta a cada proposta
